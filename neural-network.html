神经网络

一个神经元就是"加权求和再激活"；把几十个神经元叠成两层，就能围出任意弯曲的边界。本板块先讲清神经元、前向传播与反向传播三件事，再进入交互演示——看一个多层感知机如何在双月牙数据上一步步学出弯曲的分类边界。

理论与公式

Logistic 回归只有一条直线边界，遇上双月牙这样的数据就无能为力。神经网络的解法是堆叠隐藏层：每个隐藏神经元学一条"折线"，输出层把它们加权组合，边界便可以任意弯曲。训练的核心是反向传播——用链式法则把损失从输出层一层层传回，算出每个权重的梯度。

神经元与激活函数

神经元先对输入加权求和（z = w·x + b），再经过非线性激活 g。常用的 g：ReLU = max(0, z)，tanh，Sigmoid。没有非线性激活，叠多少层都等价于一条直线。

前向传播：一层层算下去

a(l) = g( W(l)a(l−1) + b(l) )

第 l 层把上一层的激活值 a(l−1) 乘上权重矩阵 W、加上偏置 b，再过激活函数。输入是两个特征，输出层用 Sigmoid 把结果压成概率 p。结构按钮里的"2×8"表示两个隐藏层、每层 8 个神经元。

损失与反向传播

L = − 1n Σ [ yi log pi + (1−yi) log(1−pi) ]
δ(l) = ( W(l+1) )⊤δ(l+1) ⊙ g′(z(l))

输出误差 δ 从损失出发，沿链式法则逐层回传（⊙ 是逐元素乘激活函数的导数），每个权重的梯度就是 δ 乘上它前面的激活值。整个过程和板块 02、03 的梯度下降一脉相承，只是梯度改由反向传播高效计算。

隐藏层为何能弯折边界

p = σ( Σj vj·ReLU(wj·x + bj) + c )

每个隐藏神经元贡献一条直线"折痕"，输出层用权重 v 把折痕拼起来：折痕够多，就能围出月牙、圆环等任意形状——这是通用逼近的直觉。权重越粗（下方面板中线条越粗）说明该连接影响越大。
