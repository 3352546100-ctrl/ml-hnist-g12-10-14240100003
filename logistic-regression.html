Logistic 回归

名字里带"回归"，做的却是分类：在线性模型外套一层 Sigmoid，把任意实数分数压成 0 到 1 之间的概率。本板块先讲清 Sigmoid、对数几率、决策边界与交叉熵损失，再看边界如何随训练一步步就位。

理论与公式

分类问题的输出是"是/否"，而线性模型 z = w·x + b 的输出是任意实数，直接当概率用既会小于 0 也会大于 1。Logistic 回归的解法是：先线性打分，再用 Sigmoid 把分数压进 (0,1)，作为样本为正类的概率估计。训练目标变成最小化交叉熵损失——下面的四个概念是读懂交互演示的全部前置知识。

Sigmoid 函数：分数变概率

σ(z) = 11 + e−z

输出范围 (0,1)、单调递增，z = 0 时恰好输出 0.5。z 越大模型越确信"正类"，越小越确信"负类"。它处处可导，导数 σ′ = σ(1−σ)，梯度计算非常方便。

对数几率：名字的由来

log p1 − p = z = w·x + b

正类概率与负类概率之比 p/(1−p) 叫做"几率"，取对数后（logit）恰好与特征呈线性关系——所以它本质上是对分类问题做线性回归，"对数几率回归"由此得名。

决策边界：一条直线分两侧

规定 p ≥ 0.5 判为正类，而 p = 0.5 等价于 z = 0，即 w₁x₁ + w₂x₂ + b = 0——特征平面上的一条直线（黑色虚线）。训练就是不断挪动这条线。

交叉熵损失：为什么要用它

L = −1n Σ [ yi ln pi + (1 − yi) ln(1 − pi) ]

预测错误且越自信，惩罚越重。若改用 MSE，损失面会变成非凸，梯度下降容易卡进坏解；交叉熵配合 Sigmoid 使损失面保持凸性，且梯度恰好是"预测误差 × 特征"，形式简洁稳定。
